THE DESIGN CHALLENGE项目概览

把复杂能力，
组织成连续的工作。

智易 Work 将对话、PPT、数据分析、图像生成与内容管理放在同一个桌面工作空间中。设计的关键，是让用户在不同任务之间，始终理解自己在哪里、现在发生了什么、接下来可以做什么。

我负责工作台的 UI 与交互设计，围绕核心任务流程、生成状态、结果预览和桌面布局建立一致的使用体验。

开始工作

让能力容易被找到

把任务入口与内容管理分开，让用户从自己的需求出发。

推进工作

让过程保持可理解

在大纲、风格、生成和预览之间，给出明确的阶段反馈。

完成工作

让结果能够被使用

把文件、预览和后续操作放在一起，衔接产出与交付。

A CLEAR START工作台架构

入口足够轻，
工作空间足够完整。

把高频任务集中在输入区附近；通过常驻导航和会话列表，保留回到既有工作的路径。

智易 Work / macOS自然语言任务入口

常驻导航

首页、素材、录音、智能体保持稳定位置，切换任务时仍能快速定位。

会话上下文

侧边栏承接历史对话与任务状态，便于回到正在进行的工作。

轻量任务入口

用常见办公能力提示用户如何开始，并保留自然语言输入的自由度。

FROM PROMPT TO PRESENTATION核心流程 / 一键 PPT

把生成过程，
交还给用户掌控。

先确认内容，再确认表达方式。将大纲编辑、风格选择与结果预览串成一条可以理解、可以介入的任务路径。

内容先于样式

先看清结构，再进入制作。

把主题、章节和内页组织为可检查的大纲，让用户在生成之前确认内容方向，减少结果完成后才发现结构不合适的情况。

对话 + 预览，同屏协作。生成与完成阶段采用左右分屏：左侧保留任务上下文，右侧呈现页面结果，让过程信息和产出内容各有位置。

ONE WORKSPACE, DIFFERENT TASKS多场景延展

同一套工作方式，
连接不同办公场景。

保留一致的导航与任务语境，再根据产出类型调整内容展示和操作方式，让功能扩展仍然有章可循。

DATA ANALYSIS

把分析产出，
变成可检查的内容。

围绕文件与数据组织预览，使内容结构与后续操作更清楚。让用户在拿走结果前，先确认它是否符合当前任务。

也有明确的下一步。

PERSONAL & ENTERPRISE

一个工作台，
清晰的身份与资源边界。

当个人使用延伸到企业场景，身份、授权与积分需要一起被看见。通过身份选择和企业积分明细，帮助用户理解当前以谁的身份工作、使用哪一份资源。
